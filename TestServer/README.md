# Belangrijk
Voeg zelf nog de benodigde plugins toe:

- OpenMinetopia + alle vereiste dependencies
- OpenGrinding + alle vereiste dependencies

# Server starten

1. Open `start.bat` in Verkenner en voer het bestand uit.
2. Kies de Minecraft-versie waarmee je de server wilt starten.
3. Wacht totdat de server volledig is opgestart.

# Plugins installeren

De plugins zijn afhankelijk van de gekozen Minecraft-versie.

1. Stop de server indien deze actief is.
2. Plaats de juiste plugins en dependencies in de map `plugins`.
3. Start de server opnieuw via `start.bat`.
4. Selecteer dezelfde Minecraft-versie als waarvoor de plugins bedoeld zijn.

Zorg ervoor dat de geïnstalleerde plugins compatibel zijn met de gekozen serverversie om fouten tijdens het opstarten te voorkomen.
